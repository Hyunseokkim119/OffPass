# OffPass — 모바일신분증 오프라인 파생 신원확인증표 (PoC)

**스마트폰을 꺼도, 맡겨도 통하는 모바일신분증.**
모바일신분증(루트)에서 용도·검증기관·유효시간이 한정된 *서명 + 암호화 QR 파생증표*를 발급해 종이·수험표·출입증에 싣고, 검증앱 오프라인 모드가 통신 없이 복호·서명검증 후 ‘서명된 사진’을 표시해 육안 대조합니다. 시험장(전자기기 금지), 군부대·보안시설(신분증 담보), 배터리 방전·통신 장애 상황을 위한 설계입니다.

- 라이브 데모(발급 → 출력물 → 오프라인 검증 → 공격 시험): **https://hyunseokkim119.github.io/OffPass/**
- 제안자: 김현석 (육군사관학교 컴퓨터과학과) — 2026 모바일신분증 아이디어 공모전 응모작

## 파이프라인
신원정보 CBOR(RFC 8949) → COSE_Sign1 / ES256 서명(RFC 9052) → 검증기관 공개키 HPKE 방식 봉투(DHKEM(P-256)+HKDF-SHA256+AES-256-GCM, RFC 9180) → Base45(RFC 9285) → QR(ISO/IEC 18004, 영숫자 모드)

| 단계 | 크기(96×120 그레이 JPEG q50) |
|---|---|
| 신원정보 CBOR | 1,840 B |
| COSE_Sign1 | 1,922 B |
| 암호화 봉투 | 1,996 B |
| Base45 | 2,998 자 |
| QR | 버전 38 / EC-M / 169×169 모듈 (단일 QR) |

오프라인 검증 중앙값 1.01 ms(50회), 실제 QR 디코더(zxing-cpp) 왕복 성공, 부정 테스트 4종(타 기관·만료·변조·재사용) 모두 거부. 상세: `poc/measurements.json`.

## 형식 검증 (ProVerif 2.05)
| 속성 | 결과 |
|---|---|
| G1 개인정보 기밀성 (종이 QR 공개 + 타 기관 키 유출 가정) | true |
| G2 위조 불가 (수락 ⇒ 발급기관이 해당 기관용으로 발급) | true |
| G3 기관 바인딩 (유출 기관용 증표의 재암호화 세탁 불가) | true |
| 대조 변형 — 서명 대상에서 기관ID 제거 | **공격 발견** (재암호화 세탁) |

```bash
proverif proverif/offpass.pv          # 모두 true
proverif proverif/offpass_nobind.pv   # 공격 트레이스 출력
```

## PoC 재현
```bash
pip install cryptography cbor2 qrcode zxing-cpp scikit-image pillow
python3 poc/offpass_poc.py            # 측정표·QR 샘플·부정 테스트 결과 생성
```

## 데모 사용법
1. **① 발급 시뮬레이터**: 신분증 종류·성명·생년월일·용도·검증기관·참조번호·유효기간 입력, 사진 업로드(또는 합성 샘플) → *파생증표 발급* → QR·단계별 크기·QR 버전 표시
2. **② 출력물 미리보기**: 종이에 인쇄될 모습(QR + 용도·기관·유효기간·마스킹 성명)
3. **③ 오프라인 검증 시뮬레이터**: 검증 단말의 기관·시뮬레이션 시각 선택 → *발급 결과 불러오기*/이미지 업로드/카메라 스캔 → 검증 로그와 ‘서명된 사진’ 표시. *타 기관 단말로 검증*, *변조 후 검증*, *동일 증표 재사용* 버튼으로 거부 동작 확인
4. **④ 설계·보안 속성**: 표준 근거와 ProVerif 결과 요약

모든 암호 연산은 브라우저 WebCrypto에서 수행되며 서버로 전송되는 데이터는 없습니다(키는 세션마다 새로 생성).
